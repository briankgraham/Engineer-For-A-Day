# PR #341: Run renewals once a day at 02:30 ET instead of hourly

**kenji-watanabe** wants to merge 2 commits into `main` from `kenji/daily-renewals` · relates to FIN-212

## Description

Finance asked for renewals to happen in **one batch per day**, so the daily revenue report lines up with a single run instead of 24. It also gets us out of Tollgate's rate limit, which we keep hitting at the top of the hour when the hourly job fires.

**Update (commit 2, "Address review"):**

- the schedule is in UTC now (07:30 UTC, which is 02:30 or 03:30 in New York), so there's no DST gap
- no more "ends today": the run renews everything that ends **before the next run**, so a missed day is caught up and nobody renews late
- replaced the daily-run test with one that checks both sides: not renewed when it ends after the next run, renewed when it ends before it
