# PR #341: Run renewals once a day at 02:30 ET instead of hourly

**kenji-watanabe** wants to merge 1 commit into `main` from `kenji/daily-renewals` · relates to FIN-212

## Description

Finance asked for renewals to happen in **one batch per day**, so the daily revenue report lines up with a single run instead of 24. It also gets us out of Tollgate's rate limit, which we keep hitting at the top of the hour when the hourly job fires.

- `jobs.js`: the renewals job runs once a day at 02:30 New York time (quietest time for our US customers)
- `renewals.js`: the daily run renews every subscription whose period **ends today**
- updated the renewals test for the daily batch, and added a test for the daily run

Would love to merge today so the first daily batch runs tonight 🙌
