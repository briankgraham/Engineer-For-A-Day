# PR #87: Retry Paystream charges on timeout

**marco-silva** wants to merge 1 commit into `main` from `marco/charge-retries` · relates to PAY-31

## Description

Paystream has been flaky this week (p95 > 2s, some requests time out). Instead of failing the checkout, we now retry the charge with exponential backoff. `maxAttempts` defaults to 3, so a customer gets up to 3 tries before we give up.

- new `chargeWithRetry(gateway, req, opts)` in `payments.js`
- `checkout()` uses it instead of calling `gateway.charge` directly
- retries are safe: Paystream already knows the `orderId`, so it won't charge the same order twice
