# PR #87: Retry Paystream charges on timeout

**marco-silva** wants to merge 2 commits into `main` from `marco/charge-retries` · relates to PAY-31

## Description

Paystream has been flaky this week (p95 > 2s, some requests time out). Instead of failing the checkout, we now retry the charge with exponential backoff. `maxAttempts` defaults to 3.

**Update (commit 2, "Address review"):**

- only retry what can succeed on a second try: timeouts, 429 and 5xx. Declines (402) fail straight away
- every attempt now sends an `Idempotency-Key`, so Paystream dedupes retries
- `log` is passed in (it was out of scope in the helper)
- `maxAttempts: 3` now really means 3 attempts, and there's no sleep after the last one
- added a test for the retry path

+// Retries a Paystream charge with exponential backoff (100ms, 200ms, ...). Declines are not retried.
+// Each attempt carries an Idempotency-Key so Paystream can dedupe it.
+async function chargeWithRetry(gateway, req, log, { maxAttempts = 3, baseMs = 100 } = {}) {
+  for (let attempt = 0; attempt < maxAttempts; attempt++) {
+    try {
+      return await gateway.charge({
+        orderId: req.orderId,
+        amountCents: req.amountCents,
+        idempotencyKey: `${req.orderId}:${attempt}`,
+      });
+    } catch (e) {
+      const last = attempt === maxAttempts - 1;
+      log.warn("charge.retry", { orderId: req.orderId, attempt, status: e.status, giveUp: last || !retryable(e) });
+      if (last || !retryable(e)) throw e;
+      await sleep(baseMs * 2 ** attempt);
+    }
+  }
