# PR #412: Highlight the matched text in search results

**dev-okafor** wants to merge 1 commit into `main` from `dev/search-highlight` · relates to KES-301

## Description

Design asked for the part of a result's title that matches what you typed to be highlighted (like Google does). This adds `highlight(title, query)` to `search.js` and uses it in `renderSearch`:

- wraps every case-insensitive match in `<mark>`
- the marked title is rendered with `raw()` so the `<mark>` tags survive
- uses the current text in the search box as the query

Seller titles are moderated and we strip HTML when a listing is created, so the titles are safe to render as they are 🙂
