# PR #412: Highlight the matched text in search results

**dev-okafor** wants to merge 2 commits into `main` from `dev/search-highlight` · relates to KES-301

## Description

Design asked for the part of a result's title that matches what you typed to be highlighted (like Google does). This adds `highlight(title, query)` to `search.js` and uses it in `renderSearch`:

- wraps every case-insensitive match in `<mark>`
- the title is HTML-escaped first, then marked, then rendered with `raw()` so the `<mark>` tags survive
- the query's regular-expression characters are escaped
- highlights against `resultsFor` (the query the results answer), not whatever is in the box now

**Commit 2, "Address review":** `escapeHtml` on the title, `escapeRegExp` on the query, and `resultsFor` instead of `query`.
