# PR #377: Page numbers and a total count for the web feed

**tariq-aziz** wants to merge 1 commit into `main` from `tariq/feed-pages` · relates to WEB-1190

## Description

The new web feed has a "page 3 of 12" control and a grid view that wants more than 50 posts at a time. `getFeed` only has cursors today, so this adds **`page` and `total`**:

- `getFeed(userId, { limit, page })` returns `{ items, page, total }`. Page 1 is the newest
- `total` is the number of posts in the user's feed, so the web client can show how many pages there are
- the `limit` cap of 50 is gone: the grid asks for up to 200, and I did not want to pick another number
- cursors keep working exactly as before

Duplicates are a normal tradeoff of paging a live list and the web client already dedupes by post id, so I did not try to do anything clever for new posts arriving between pages 🙂

Would love to merge before the web release on Friday 🙏
