# PR #377: Page numbers and a total count for the web feed

## Description

The new web feed has a "page 3 of 12" control and a grid view. This adds **`page` and `total`** to `getFeed`.

**Update (commit 2, "Address review"):**

- `limit` is capped at 100 again (the grid asks for 60)
- `page` must be an integer of 1 or more, otherwise `RangeError`
- `total` is **cached for 5 minutes per user** (`store.totals`), so we no longer count the whole feed on every page request
- a page past the last one returns `{ items: [], page, total }` instead of throwing
- added tests for the validation and for a page past the end
